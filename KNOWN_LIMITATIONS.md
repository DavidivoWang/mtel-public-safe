# Known limitations

- The supported request vocabulary is intentionally limited to the kinds and nested fields defined in `schemas/when_input_v0_2.schema.json`.
- Includes are local and bounded; there is no remote module registry.
- Migration is documented but no automatic migration tool is supplied.
- Benchmark numbers describe only the runner on which they were observed.
- This repository is a smaller condition-dispatch candidate, not the complete private MTEL runtime.
